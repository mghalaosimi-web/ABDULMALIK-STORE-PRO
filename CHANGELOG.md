# Changelog

All notable product changes should be recorded here. This file begins with the state documented by the imported source snapshot; it does not claim that every item has passed production acceptance.

## 1.1.0 (source version 1.1.0+16)

- Windows x64 remains the primary delivery target.
- Accessories section is separated from general inventory using the shared products model and section filtering.
- Product images and custom phone templates are supported in the current source.
- Saudi phone-number and identity-format handling was added while retaining compatibility with legacy Egyptian records.
- Arabic/English localization and project profile/about navigation were expanded.
- Firebase configuration is empty and cloud sync/public tracking are disabled by default in the current delivery profile.
- Windows CI includes analysis, automated tests, installer creation and silent install/uninstall validation.

See `docs/ACCESSORIES_AND_PROGRESS.md`, `docs/PHASE2_QUALITY_REVIEW.md`, and `docs/COMPREHENSIVE_PROJECT_STUDY.md` for detailed context and known limitations.
